# The Cozy Quill — Stage 1 Shop Preview

Front-end staging demonstration of the Shop and Product pages for
[thecozyquill.au](https://thecozyquill.au).

This is a static preview of the presentation layer only. Colours, typography,
header and footer are taken directly from the live site's existing stylesheet
so the shop reads as part of the same brand.

- `index.html` — Shop page
- `product.html` — Blind Date With a Book product page
- `assets/css/shop.css` — shop stylesheet
- `assets/js/shop.js` — genre/spice selection, stock states, gift toggle, live matchmaking summary

Pricing and photography are placeholders. Cart, checkout, Square payments,
order emails and the admin area are built in Stages 2–5 inside the existing
Laravel application.
